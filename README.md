# 小劇場LPドラフトジェネレータ

小劇場や自主公演向けのランディングページを、ブラウザ上で組み立ててそのまま `HTML` として出力できる静的ジェネレータです。

フォームに公演情報を入力すると、右側のプレビューが即時更新されます。完成後は、見た目込みの単体 `HTML` をダウンロードできます。

## できること

- 公演情報、あらすじ、見どころ、キャスト、スタッフ、日程、チケット、アクセス、FAQ、お問い合わせを入力
- セクションごとにアコーディオンで開閉
- 一部セクションは出力ON/OFFを切り替え可能
- 色や角丸、余白、ボタン色などのデザイン調整
- `Hero` とキャスト画像はURL入力またはローカル画像選択に対応
- 入力内容をブラウザに自動保存
- `JSON` で設定データの保存 / 読込
- 見た目込みの単体 `HTML` をダウンロード
- 既存ページへデザインを移したい場合の `CSS` ダウンロード

## 使い方

1. `index.html` をブラウザで開きます。
2. 左側フォームに必要な情報を入力します。
3. 右側プレビューで見た目を確認します。
4. `データ / 出力` から `完成HTMLをダウンロード` を押します。

ローカルサーバーで開く場合は、このフォルダで以下を実行して `http://localhost:8000` を開いてください。

```powershell
python -m http.server 8000
```

## ファイル構成

- `index.html`
  ジェネレータ本体のUI
- `style.css`
  ジェネレータUIのスタイル
- `script.js`
  入力管理、プレビュー生成、保存、出力処理

## 出力について

- `完成HTMLをダウンロード`
  そのまま公開や共有に使える、見た目込みの単体 `HTML` を出力します
- `CSSダウンロード`
  既存サイトや別ページへ配色やデザインだけ移したいときに使います
- `設定データをダウンロード`
  入力内容を `JSON` で保存します

## 画像について

- `Hero` 画像の推奨サイズは `1600px x 900px` 以上です
- キャスト画像の推奨サイズは `1000px x 1000px` 以上です
- ローカル画像を使う場合、ファイルサイズは `1MB` 以下を目安にしてください
- ローカル画像は完成 `HTML` に埋め込まれます

## 注意点

- ブラウザ保存は `localStorage` を使っています
- ローカル画像を多く使うと、保存容量の上限に達することがあります
- 画像URLやリンクURLは、出力前チェックで最低限の確認を行います
- このツールは静的なLP生成向けで、CMSや公開ホスティング機能は含みません
